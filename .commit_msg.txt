perf(dirty-surface): dirty-region compositor, persistent Pixmap, MT raster, UI dirty

Stage 1 - dirty-region compositor (A1~A7):
- Compositor composites only the merged dirty bands: UI base -> surfaces by z ->
  re-blit higher-z UI occluders (Group expanded recursively, popups not covered).
  sync_surfaces marks stale rects (moved/resized/gone) to prevent ghosting.
- Drop per-frame 8MB backing clone (mem::take + refill); replace O(W·H·S) per-pixel
  coverage check with rect copy_from_slice spans.
- Pixel contract: backing/UI premul, SharedSurface straight RGBA with src-over blend
  (a==255 memcpy fast path).
- SharedSurface: Drop auto-unregisters; resolve_surface lazy-removes dead Weak;
  is_touched skips untouched surfaces; merge_rects integrated (no dead code).
- present_with_damage (fallback to full present when age==0 or dirty >=70%);
  examples/perf_surface.rs benchmark; docs/dirty-surface-review.md as baseline.

Stage 2 batch 1 - rasterization cost cut:
- VelloRenderer keeps a persistent cross-frame Pixmap (no Pixmap::new per frame);
  Renderer trait returns &Pixmap; pixmap_bytes() consumed directly by compositor.
- vello_cpu multithreading via `parallel` feature (default on); LIEUI_RENDER_THREADS
  overrides thread count (0=auto, 1=force single).
- UI dirty-region detection via element content signatures (DefaultHasher); conservative
  degradation to full-frame when bounding box is unknown (Group) or element count changes;
  LIEUI_UI_DIRTY=0 disables.
- app.rs: split present_frame into free fn composite_frame + blit_damage (disjoint borrow).

Tests: cargo test 16 suites green (116 cases). clippy clean for changed files.
